## Чат-бот с RAG и ReAct агентом

### Описание

Веб-приложение на базе FastAPI, реализующее интеллектуального чат-бота с использованием RAG (Retrieval-Augmented Generation) и ReAct агента с Function Calling.

Проект представляет собой ReAct агента, призванного выяснить наличие/вид юридического лица, наличие указанного вида экономической в ОКВЭД и статус налогового резидентства. На основании предоставленных пользователем данных агент принимает решение о подключении пользователя к сервису или отказе в подключении.

Проект полностью автономен, и не использует внешних API/LLM.

_В папке demo_screenshots примеры работы чат бота_

### Cтек

Язык программирования: python (core) / js (UI)

Backend: FastAPI (асинхронный веб-фреймворк)

WebSocket: Real-time двусторонняя связь с клиентом

Хранилище векторов Chroma: Для семантического поиска по документам

Шаблонизатор: Jinja2 для HTML страниц

Статика: Отдельные директории для HTML/CSS/JS файлов

LLM: локальная Ollama c QWEN 2.5:14b

### Ключевые компоненты

1. Управление жизненным циклом (lifespan)
При запуске: подключение к базе данных (векторное хранилище)

Инициализация RAG системы с готовым векторным индексом

Graceful shutdown при остановке

2. Маршруты
GET / - Главная страница чата (WebSocket клиент)

WebSocket /ws - Основной канал обмена сообщениями

3. Функциональность WebSocket
Таймаут сессии: 15 минут неактивности (настраивается через TIMEOUT)

Лимит длины сообщений: Ограничение длины текста через USER_MESSAGE_SIZE

Лимит числа сообщений: Ограничение количества сообщений, попадающих в контекст LLM через MAX_CHAT_HISTORY

Асинхронная обработка: Неблокирующая работа с очередью сообщений

История чата: Поддержание контекста беседы

4. Архитектура агента
ReAct агент: Логика "Reasoning + Acting" для продуманных ответов

Интеграция с RAG: Поиск релевантной информации из базы знаний

Поддержка LLM: Использование языковой модели через конфигурацию

Реализация Function Calling для проверки экономической деятельности в ОКВЭД и подключения к сервису

### Особенности реализации

✅ Асинхронность - Полное использование async/await для высокой производительности
✅ CORS поддержка - Возможность интеграции с любыми фронтенд приложениями
✅ Обработка ошибок - Graceful обработка таймаутов и отключений клиентов
✅ Конфигурируемость - Настройки через модуль config (LLM, таймауты, etc.)
✅ Модульность - Разделение логики (rag, database, tools, agent, websocket_handler)

### Поток данных
Пользователь открывает страницу чата (/)

Устанавливается WebSocket соединение (/ws)

Клиент отправляет текстовое сообщение

### Агент:

Получает историю чата

Запрашивает RAG систему для поиска контекста

LLM генерирует ответ на основе найденной информации

Ответ отправляется клиенту через WebSocket

При неактивности 15 минут - соединение закрывается с уведомлением

#### Потенциальные сценарии использования

Корпоративный помощник по документации
Чат-бот поддержки клиентов
Интеллектуальная поисковая система по базе знаний
Образовательный инструмент для работы с учебными материалами
